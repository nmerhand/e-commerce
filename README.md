# E-commerce

Application e-commerce simple en cours de développement.

## Stack prévue

- TypeScript, React et Vite pour l'interface web
- Node.js et Express pour l'API REST
- PostgreSQL et Prisma pour la base de données
- Docker Compose pour l'environnement local

## Fonctionnalités prévues

Catalogue avec recherche, panier, comptes client, passage de commande avec paiement simulé et administration des produits et commandes.

## État du projet

Le dépôt et les fichiers de configuration initiaux sont en cours de mise en place. Les instructions d'installation, de lancement et de test seront complétées au fil des étapes de développement.

## Configuration

Copier `.env.example` vers `.env` et remplacer les valeurs de développement avant de lancer les services. Ne jamais versionner `.env` ni y placer de secrets réels.
